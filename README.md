## 🚀 Executando localmente

### Pré-requisitos

- Node.js
- npm

### Instalação

```bash
git clone https://github.com/laurateresa-code/MeuPortfolio.git
cd MeuPortfolio
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
